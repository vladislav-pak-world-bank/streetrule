Method and evidence

How an answer is produced, how we know it holds, and where it stops. Every number on this page is computed from the files in the repository.

The pipeline

The model reads; arithmetic decides. Language models extract text into fields, and every decision about an address is deterministic code you can test.

1. ExtractEach document goes to the model with a strict JSON schema. Quotes not found verbatim in the source are discarded.
extract.py
2. ThresholdsCoverage text becomes fields: cutoff dates, unit limits, exemptions. Contradictory cutoffs are dropped.
extract.py
3. ReviewHuman fixes live in one file, each with a reason and, for thresholds, a verified quote.
review/corrections.json
4. LocateThe US Census Geocoder gives each address its incorporated place. Matches to another house number are rejected.
geocode.py
5. DecideStatus against the query date, then each threshold against the building's facts. Every check is returned.
core/coverage.py

Against a naive baseline

The naive baseline is what most lookups do: take the mailing city and list every rule for that city and state.

What the tests check

The automated suite (uv run pytest) runs over every extracted rule, not one example.

  • Every quote appears in its source document.
  • Every rule's jurisdiction matches the document it came from.
  • A rule marked in force never has an effective date after the query date, and the reverse.
  • A numbered ordinance with a recorded vote is never labeled a bill; an unsigned draft is never labeled law.
  • Certificate-of-occupancy cutoffs return unknown for a building in the cutoff year, as the brief requires.
  • A supplied fact settles an unknown; a match to a different house number is rejected.
  • Change tests T1–T5 produce the behavior the brief expects.

Where it stops

Stated so nobody relies on what isn't there.

  • Hoboken's ordinances, Jersey City's algorithmic ban, Newark's code and the struck Massachusetts ballot question are links with no text in the corpus. Those addresses list the links instead of inventing rules.
  • San Diego's algorithmic ordinance in the corpus is an unsigned draft, so it stays pending.
  • Los Angeles's second published RSO date (2026-01-24, per a landlord association) is not in the corpus, so only LAHD's date is shown.
  • Owner names are excluded from the data, so owner-type exemptions stay unknown unless a user supplies the fact.
  • Not legal advice. A research prototype on a fixed corpus as of 1 Oct 2026.
